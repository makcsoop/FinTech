# Honey Money — демо «Мани читает новости за вас»

Одностраничный демо-сайт новостного модуля Honey Money. Главное на странице —
«консоль»: слева примеры и поиск, справа ответ Мани по выбранной новости.
Решение остаётся за пользователем и попадает в журнал решений.

Чистый HTML/CSS/JS, без сборки и библиотек. Цвета и шрифт — из брендбука:
графит `#151512`, лайм `#DFF867`, крем `#EDE9E1`, Manrope, медоед Мани,
лаймовая «змейка» со слайдов.

## Что на странице

1. **Первый экран** — крупный заголовок с выглядывающим Мани, «живые» чипы с
   реальными оценками и бегущая лента сигналов из отчёта (клик открывает разбор).
2. **Демо** — консоль: 8 примеров и поиск слева; справа вердикт одним словом
   («Плюс», «Минус», «Шум»), шкала влияния со стрелкой, кольца уверенности и
   значимости, блок «Главное» и вкладки «Проверки / Что в тексте / Спор
   AI-аналитиков / Сверка с банком». Внизу — «Ваше решение».
3. **Проверили вслепую** — крупные цифры итогов, график верного знака с
   интервалами (подсказки при наведении) и разборы, где Мани прав и где ошибся.
4. **Семь шагов** — этапы оценки (подсвечиваются при наведении), «змейка»
   рисуется при прокрутке, место модуля в цепочке Honey Money.

**Живой Мани и эффекты** (`assets/js/fx.js`, `assets/css/fx.css`):

- заставка — Мани бежит через лаймовый экран, пока читается отчёт (счётчик 0→100%);
- на первом экране Мани следит за курсором и подпрыгивает, буквы заголовка
  пробегают волной и подскакивают при наведении, за курсором — лаймовый луч;
- «дорожка» между демо и цифрами — Мани бежит по мере прокрутки (в обе стороны);
- Мани-компаньон в углу: комментирует разделы, думает с ноутбуком, пока идёт
  разбор, меняет позу по вердикту, радуется решению; по клику — факт из отчёта;
- частицы: монеты ₽ на позитив и на «Действую», «!» и тряска на негатив, «z» на шум;
- магнитные кнопки, наклон карточек с бликом, числа «набегают» от нуля,
  курсор с подписью, полоса прогресса прокрутки.

При «уменьшить движение» в системе заставка и анимации отключаются.

Ссылка на конкретный разбор: `index.html#N26` (в живой ленте — тикер, например `#VTBR`).

## Откуда данные

Два режима, сайт выбирает сам:

| Режим | Когда | Демо и первый экран | «Проверили вслепую» |
|---|---|---|---|
| **Живая лента** | сайт открыт через `live/server.py` (сервер Honey Money) | живая лента новостей и оценки агента новостей | из отчёта |
| **Отчёт** | GitHub Pages, `file://`, `tools/serve.py` | `news_scoring_report.html` | из отчёта |

### Живая лента

На сервере сайт работает вместе с новостной частью Honey Money: сборщик читает ленты, сайты и
Telegram, агент новостей раз в 15 минут оценивает бумаги от −1 до +1. Торговая часть и её настройки
в публичную версию не входят, сделок сайт не совершает.

Карточка на сайте — одна на бумагу: оценка агента, уверенность, объяснение, заголовки, на которые он
сослался («учёл агент»), и остальные заголовки по бумаге. Если агент бумагу не оценил — «нет данных».
Бегущая лента — цены первого эшелона (индекс MOEXBC): T-Invest API или ISS Мосбиржи, только для показа.

API сайта: `GET /api/live` — карточки в той же форме, что карточки отчёта; `GET /api/prices` — котировки;
`GET /api/health`. Выкладка на сервер — `deploy/deploy.sh` (systemd, Caddy с HTTPS).

### Отчёт

В этом режиме разборы сайт **читает из `news_scoring_report.html`** при загрузке —
вручную в коде записаны только заголовки 8 примеров (`SCENARIOS`) и короткие
подписи этапов (`HELP`) в `assets/js/app.js`.

- `assets/js/report.js` разбирает отчёт: сводку, этапы, 36 карточек исходного
  набора, 44 новости слепого теста, интервалы и 7 разобранных примеров.
- Если страница открыта двойным кликом (`file://`), берётся встроенная копия
  `data/report-embed.js`.
- В подвале есть ссылка «загрузить свой отчёт» — всё перерисуется по новому
  файлу того же формата.

Обновить отчёт:

```bash
python3 tools/embed_report.py                       # возьмёт ../news_scoring_report.html
python3 tools/embed_report.py путь/к/новому_отчёту.html
```

## Запуск

Живая лента — `tools/live.sh` (см. выше). Только отчёт — двойной клик по `index.html` или локальный сервер без кэша:

```bash
python3 tools/serve.py
```

→ http://localhost:8765

## Структура

```
index.html
assets/css/base.css   — токены бренда, кнопки, общие элементы
assets/css/app.css    — интерфейс демо
assets/js/report.js   — ← ТОЧКА ИНТЕГРАЦИИ: чтение отчёта и живой ленты (loadLive, withLive)
assets/js/app.js      — лента, консоль с ответом Мани, журнал, графики
assets/js/fx.js       — живой Мани и эффекты (слушает события mani:* из app.js)
assets/css/fx.css     — стили эффектов
assets/img/           — логотип, favicon, медоед Мани (webp)
data/                 — отчёт и его встроенная копия
live/server.py        — живой режим: сайт + /api/live, /api/prices
live/cards.py         — перекладка выхода модели в карточки фронта (ничего не досчитывает)
tools/                — live.sh (живой режим), embed_report.py, serve.py
```

Журнал решений хранится только в браузере пользователя (localStorage).
Все пути относительные — папку можно выложить в любую подпапку сервера.
